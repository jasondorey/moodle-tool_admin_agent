# React / ESM frontend (Moodle 5.2+)

Chat UI lives here. Admin configuration (skills, placements, functions) stays on Mustache + AMD.

## Layout

```text
js/esm/
├── src/     # TypeScript / TSX (edit here)
└── build/   # Generated by `grunt react` — ship this in releases
```

Mount specifier: `@moodle/lms/tool_adminagent/ChatApp`

## Build

From the Moodle 5.2 root (Grunt installed), after editing `src/`:

```bash
npx grunt react --root=public/admin/tool/adminagent
```

Then copy `js/esm/build/` back into this repository.
